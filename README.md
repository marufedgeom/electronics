# ROBIUL ELECTRONICS · ERP 2027

Complete ERP system with:
- Barcode Scanner (camera + manual)
- POS with VAT & OMR currency
- Inventory, Accounts, Expenses, Services
- Image Editor with rotate/reset
- Multi-language (EN, BN, AR)
- Dark/Light theme
- Developer settings panel

## How to Run
1. Open `index.html` in any modern browser.
2. No server required — works fully client-side.

## Features
- Real-time barcode scanning via Html5Qrcode
- 3-decimal OMR currency formatting
- RTL support for Arabic
- Recycle Bin with restore/purge
- Backup & Restore simulation
- Image editor with canvas manipulation
